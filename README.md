#  🌴 Honeymoon - Romantic Destination Picker 
A beautiful SwiftUI app for couples to discover and pick their perfect honeymoon destination with intuitive card swipe gestures.  
## Features   
 ✨ Features
🎴 Swipeable Card Interface - Tinder-like card swiping for destination selection

💖 Gesture Controls - Swipe right to like, left to dismiss

🎵 Haptic Feedback - Tactile responses for user interactions

🎨 Beautiful UI - Custom animations and transitions

📱 Responsive Design - Optimized for all iPhone sizes

🌍 20+ Destinations - Curated list of romantic locations worldwide  
## 🎯 How to Use  
1. Browse Destinations: Swipe through beautiful honeymoon destinations

2. Like a Destination: Swipe right or tap the heart icon

3. Skip a Destination: Swipe left or tap the X icon

4. Book a Destination: Tap the "Book Destination" button

5. Get Help: Tap the question mark icon for usage guide

6. App Info: Tap the info icon for app details
